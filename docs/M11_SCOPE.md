# M11 scope: Evidence-aware response policy

Qualification: **bounded source framing and runtime boundaries**.

Development is concluded. The original semantic-reliability hypothesis and the separate,
post-development-authored Foundation hypothesis were **not adopted as complete response
policies**. Their unchanged frozen evaluations and failed development screens remain the
record of those hypotheses. Neither original nor Foundation holdout was generated,
inspected, scored or spent. No further candidate development is authorized.

See [final development conclusion](M11_DEVELOPMENT_CONCLUSION.md). Infrastructure retained
in production is distinct from semantic-policy adoption: typed supplied entries, origin
metadata, lossless escaping/order, compact information/origin framing, a scoped project
observation warning, the Dwindy-only capability fact, native history and existing budgets,
transience and lifecycle boundaries. Origin does not prove truth, verification or priority.

The direct Foundation v2 wording states that Dwindy (this assistant) cannot perform actions
in the host application. It was correctly supplied as a trusted runtime fact, yet both
host-action development cases still omitted the required explicit verbal boundary (0/2).
Informational HOST controls remained correct without new refusals/disclaimers. Representing
Dwindy's capability is deterministic; reliably expressing it in an answer is not guaranteed.

Evidence-aware does not mean evidence-dependent. Ordinary knowledge, reasoning, writing and
conversation remain available. Native history is context, not verified evidence; there is
no quoted-history demotion, history-only global policy, semantic classifier, output rewrite,
verifier, second generation, extra setting, dependency or public confidence field.

Arbitrary semantic conflicts, unsupported historical claims, partial support, absence versus
contradiction, mixed attribution and factual self-consistency remain best-effort limitations.
The experiments do not guarantee injection immunity or reliable verbal action boundaries.
These goals are not automatically moved into M12, which remains optimization/V1 hardening.
Reach/H2 stays deferred and unchanged. The dormant WEB/facts path is restored to M10.
